# RegHive

Плагин Lister (WLX) для Total Commander, который читает **сырые, автономные
файлы кустов реестра Windows** — те самые файлы, которые обычно нельзя
просто открыть, потому что Windows держит рабочий реестр заблокированным.
Только для чтения; RegHive никогда не изменяет открытый файл.

Типичный сценарий: копия `NTUSER.DAT`, `SOFTWARE`, `SYSTEM` и т. д. из
резервной копии, старого диска или подключённого образа — файлы, которые
иначе пришлось бы сначала подключать в рабочий реестр командой `reg load`
только для того, чтобы в них заглянуть.

## Что умеет плагин

- Распознаёт и разбирает сырые файлы кустов: `SYSTEM`, `SOFTWARE`, `SAM`,
  `SECURITY`, `DEFAULT`, `NTUSER.DAT`, `UsrClass.dat`, `*.hiv`
- Дерево разделов слева, таблица значений (Имя / Тип / Данные / Подсказка)
  справа — клик по разделу показывает его значения
- Декодирует все распространённые типы значений: `REG_SZ`,
  `REG_EXPAND_SZ`, `REG_MULTI_SZ`, `REG_DWORD`, `REG_QWORD`; `REG_BINARY`
  показывается в виде HEX-превью
- Показывает время последнего изменения каждого раздела
- **Столбец-подсказка о переносимости**: отмечает значения, которые,
  вероятно, не переживут перенос на другой компьютер/учётную запись — ссылки
  на SID, жёстко заданные пути к дискам или пути с переменными окружения
- Правый клик на значении копирует его имя, данные, "имя = данные" или
  открывает **полный HEX+ASCII-дамп** в отдельном окне (закрывается по Esc)
- **Поиск** (Ctrl+F в Lister) подключён к собственному диалогу поиска Total
  Commander — ищет по именам разделов, именам значений и содержимому
  строковых значений; учитывает "учитывать регистр"/"назад", всегда
  продолжает с текущей позиции курсора в дереве
- **Alt+F3** (следующий/предыдущий файл) использует то же окно вместо
  открытия нового
- **Режим сравнения**: правый клик по дереву → "Сравнить с файлом..."
  сравнивает два файла кустов. Разделы/значения помечаются как `[+]` (есть
  только в файле B), `[-]` (отсутствует в файле B), `[~]` (изменено где-то
  ниже) или без пометки (идентично)
- Интерфейс доступен на немецком, английском, русском и украинском
  языках; язык автоматически следует языку Total Commander (см. раздел
  «Язык»)

## Установка

Скопируйте `RegHive.wlx64` (64-битный Total Commander) и/или `RegHive.wlx`
(32-битный), а также `reghive.lng` в папку плагинов TC, затем добавьте
плагин через *Конфигурация → Настройки → Плагины → Lister-плагины* (или
используйте прилагаемый `pluginst.inf`).

## Язык

Язык интерфейса автоматически следует языку Total Commander. Файл
`reghive.lng` (в той же папке, что и DLL) содержит по одному разделу на
язык; RegHive использует раздел, имя которого совпадает с последней
частью имени текущего языкового файла TC — `WCMD_DEU.LNG` выбирает
`[deu]`, `WCMD_RUS.LNG` — `[rus]`. Включены разделы `[eng]`, `[deu]`,
`[rus]` и `[ukr]`. Если раздел, ключ или сам файл отсутствует,
используется английский язык.

Чтобы задать язык независимо от TC, укажите его в `reghive.ini` (та же
папка, что и DLL):

```ini
[Settings]
Language=ru
```

Допустимые значения: `auto` (по умолчанию) или код языка, например
`eng`, `deu`, `rus`, `ukr` (короткие формы `en`, `de`, `ru`, `uk` тоже
работают).

## Известные ограничения

- Очень большие кусты (обычно `SOFTWARE`/`SYSTEM` на давно используемых
  системах) могут использовать формат косвенных списков подразделов
  (записи `ri`), который пока не разбирается — затронутые поддеревья
  просто пропускаются, не вызывая сбоя.
- Режим сравнения не распознаёт переименованные разделы как
  "переименованные" — переименованный раздел отображается как один
  удалённый и один новый элемент.
- Поиск и HEX-просмотр недоступны в режиме сравнения.
- Сознательно только для чтения — функция редактирования не планируется.
